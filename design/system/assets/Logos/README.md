# Logos

The Route mark: two past stops and a vermilion stop for now. The inks are fixed per file, because `<img>` can't inherit color.

- `workbus-lockup.svg`: mark plus wordmark, ink `#12141a` with a `#d63f18` now-stop. Use on `bg`, `sidebar` and `surface` in the light theme.
- `workbus-lockup-dark.svg`: ink `#eceef2` with a `#ff6a3d` now-stop. Use in the dark theme.
- `workbus-mark.svg` / `workbus-mark-dark.svg`: the mark alone, same inks. Use where the name is already present.
- `workbus-app-icon.svg`: the mark in white and vermilion on an ink tile with 7/32 corner radius. For favicons and app icons.
- `workbus-wordmark.svg`: the wordmark alone, ink `#12141a`, Geist SemiBold outlined. Rarely needed: prefer the lockup.

Smallest lockup: 20px tall. Smallest mark: 16px wide. Clear space: the now-stop's diameter.
