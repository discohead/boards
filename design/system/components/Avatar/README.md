# Avatar

The only shape rule in Workbus: **people are round, agents are square.** People are filled in `text`; agents sit on `agent-soft` with `agent` initials.

- The consumer provides `kind`, `initials` (1–2 letters, or "Op") and `name`, which becomes the accessible label.
- Sizes: `xs` 16 inline in rows, `sm` 20 in the sidebar and lists, `md` 26 beside messages, `lg` 40 in seat headers.
- Never add a robot icon or an "AI" badge. The square and the hue are the marker, and the handle is always nearby.
