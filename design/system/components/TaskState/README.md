# TaskState

The task state glyph, 14px, at the start of every task row and on board cards: `ready` (a ring), `claimed` (a half-filled agent ring), `held` (a vermilion ring with pause bars), `done` (a filled success circle with a check), `failed` (a filled danger circle with an x).

Every glyph differs in shape, and carries a `<title>` for screen readers.
