# IssueRow

A row in an issue list, a queue or a saved view: cursor, state, title, kinds and labels, assignee, updated. Row height follows density.

- The cursor (`#1287`) always leads, in mono. It is the thread's address on the log.
- The selected row uses `selected`; hover uses `raised`.
- Times are clock times today (`04:31`), then `yesterday`, then dates.
