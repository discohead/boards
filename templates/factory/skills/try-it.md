# Try your work for real

Tests tell you some of it; using the thing tells you the rest: run the command, call the endpoint, start the server and curl it.

- **Your sandbox** has the repo, what it installs, and what you make there.
- **GitHub reaches you;** other services don't, unless the factory is set up for them. Don't ask for a password or a key to be put in your sandbox: it never arrives. Say what you'd need set on the factory instead.
- **A person can do what happens outside your sandbox:** make an account, change a setting, try one step and say what they saw. Get as far as you can first, then ask once, for all of it.

When you find a way, show it once in the thread (what the command printed), and write it down in the repo's AGENTS.md: what to run, what it needs, what can't be tried. The next thread starts from there.
